# Day_Tracker

**Win the day. Every day.**

A personal "life OS" web app for tracking daily habits, fitness, reading, coding, academics, goals, and journaling — with XP, levels, streaks, and a GitHub-style consistency heatmap.

Built as a single self-contained HTML file (no build step, no backend). Open it directly in a browser, or install it to your phone's home screen like an app. Your data is saved automatically as you use it.

## How to use it

1. Download `day_tracker.html` from this repo
2. Open it in Chrome (desktop or Android)
3. Optional: use the browser's "Add to Home Screen" option to install it like an app

No installation, accounts, or internet connection required after the first load.

## Tech

- Plain HTML/CSS/JavaScript — no frameworks, no build tools
- Dark AMOLED theme with a glassmorphism UI
- Space Grotesk / Inter / JetBrains Mono typefaces
- Local, on-device data persistence
